# 精简 DMG 产物并增加应用程序快捷入口

## 需求和范围

构建下载产物仅保留 DMG；DMG 中提供应用和指向系统应用程序文件夹的快捷入口，可直接拖拽安装。保留当前手动触发构建方式。本次不重新编译或触发云端构建。

## 实现变化和涉及文件

- `.github/workflows/macos-icons.yml`：取消应用 ZIP、截图、日志、提交号与校验和文件的产物输出。
- 删除不再使用的截图生成和辅助打开应用步骤，保留已有签名、架构、依赖与进程启动检查。
- 使用独立临时目录暂存 `Nextpad++.app` 和 `Applications -> /Applications` 符号链接，再生成 UDZO DMG。
- 磁盘映像生成后执行完整性校验；退出时清理暂存目录。
- 上传范围限定为 `dist/*.dmg`，没有 DMG 时明确失败。
- 本交接记录。

## 验证命令与结果

- 将三个工作流 `run` 脚本分别交给 `/bin/bash -n`：全部通过。
- `git diff --check`：通过。
- 使用此前已构建的 v1.1.2-rc1 应用，通过 `ditto` 复制并执行 `ln -s /Applications`：通过；未编译或启动应用。
- `hdiutil create -volname Nextpad++ -srcfolder <暂存目录> -ov -format UDZO <验证映像>`、`hdiutil verify <验证映像>`：通过。
- `hdiutil attach -readonly -nobrowse -mountpoint <验证挂载点> <验证映像>` 后读取目录：可见项恰好为 `Applications` 和 `Nextpad++.app`。
- `readlink <挂载点>/Applications`：结果为 `/Applications`，确认是符号链接。
- `codesign --verify --deep --strict <挂载点>/Nextpad++.app`：通过；随后 `hdiutil detach` 成功。
- 独立只读代码复核：未发现阻塞问题。

## 临时测试清理

验证证据摘要已记录于本文。开发期间创建的验证映像、暂存应用、挂载目录和临时 JSON 结果均已清理；未新增测试脚本、测试源码或专用构建入口到仓库。保留任务开始前已有的应用与其他任务产物。

## 使用方式和已知限制

在 GitHub Actions 手动运行工作流，完成后下载产物。GitHub 网站仍会使用 ZIP 容器下载 artifact，但其中只包含一个 DMG。打开 DMG，将 Nextpad++.app 拖到 Applications 快捷文件夹即可安装。

本次验证覆盖打包与挂载结构，使用的是此前已有的应用，不代表已重新编译当前最新源码；没有触发云端构建，也未实际覆盖本机 /Applications 中的应用。macOS 27 的 hdiutil 提示工具弃用警告，但验证成功；现有云端 runner 使用 macOS 26。
